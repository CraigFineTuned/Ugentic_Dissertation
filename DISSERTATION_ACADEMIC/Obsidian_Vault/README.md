# Obsidian Vault for Dissertation

This folder contains an Obsidian-compatible knowledge base for managing the dissertation.

## How to Use

1. Open Obsidian
2. Click "Open folder as vault"
3. Select this `Obsidian_Vault` folder
4. Start with `00_COMMAND_CENTER.md`

## Files

- `00_COMMAND_CENTER.md` - Main dashboard
- `Sample Dissertation Structure.md` - Required format
- `Interview Data Index.md` - All 14 participants
- `UGENTIC System Map.md` - System architecture
- `Research Questions.md` - RQ1-RQ4 mapping
- `Jemini Feedback Tracker.md` - Supervisor requirements
- `Richfield Compliance Checklist.md` - All requirements
- `UGENTIC Test Scenarios.md` - Test prompts for app.py
- `IMMEDIATE ACTION LIST.md` - Priority tasks
- `File Cleanup Log.md` - Redundant files to delete
